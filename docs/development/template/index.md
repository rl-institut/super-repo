# Use as Template

This repository is designed as a template for new research software repositories. <br>
To create a new repository, use the 🐙 `Use this template` button on GitHub or copy the repository.

Afterwards, the repository needs to be adapted to the new project,
e.g. names and URLs, package, metadata, licensing, changelog, badges and GitHub settings. <br>
The complete checklist is contained in the section *Deriving a new repository from this template*
of the 📝 [AGENTS.md](https://github.com/rl-institut/super-repo/blob/production/AGENTS.md). <br>
It can be worked through manually or together with an AI coding agent, which reads the 📝 `AGENTS.md` automatically.
